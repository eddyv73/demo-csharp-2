# demo-csharp-sec

Solución base de .NET con un proyecto de consola en `src/demo-csharp-sec`.
## Justificación

Este proyecto está pensado para una demostración en vivo sobre el uso de Copilot y para enseñar a escribir correctamente.

## Estructura

```text
src/
  demo-csharp-sec/
doc/
test/
readme.md
demo-csharp-sec.sln
```

## Compilar y ejecutar

```bash
dotnet build demo-csharp-sec.sln
dotnet run --project src/demo-csharp-sec/demo-csharp-sec.csproj
```
